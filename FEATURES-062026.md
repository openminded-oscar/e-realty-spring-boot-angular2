Функціонал, згрупований за ролями. Ролі накопичувальні: REALTOR має все від USER, ADMIN — усе.

## 👤 Гість (без авторизації)
- Перегляд галереї об'єктів — продаж і оренда
- Фільтрація (ціна, регіон, тип житла/будівлі, площа, поверхи) + сортування
- Геопошук на карті (за координатами + зум)
- Перегляд деталей об'єкта (фото, опис, характеристики, контакт рієлтора)
- Список рієлторів + пошук за ім'ям
- Реєстрація / вхід (email-пароль, Google passwordless), скидання пароля

## 👤 USER (звичайний користувач)
**Автентифікація / профіль**
- Редагування профілю (ім'я, прізвище, телефон, фото)

**Власні об'єкти**
- Створення об'єкта (майстер у 3 кроки) + завантаження фото (головне, галерея, документ підтвердження)
- Редагування, видалення
- Архівування / відновлення власного об'єкта
- «Мої об'єкти» з фільтром за статусом (active / archived / draft)

**Огляди (як відвідувач)**
- Запис на огляд об'єкта з вибором дати й доступного слоту
- Перегляд доступних слотів
- «Мої огляди» (майбутні / минулі / непідтверджені)
- Скасування свого огляду (з причиною)
- Подія в Google Calendar (якщо OAuth)

**Обране**
- Додати / видалити в обране, перегляд списку обраного, лічильник популярності (лайки)

## 🏢 REALTOR (усе від USER +)
- «Мої об'єкти як рієлтор» (`/my-as-realtor`)
- «Огляди як рієлтор» — огляди по об'єктах, де він рієлтор
- **Підтвердження огляду** (`/object-review/{id}/approve`) — лише REALTOR/ADMIN
- **Активація об'єкта** (`/realty-objects/{id}/activate`) — REALTOR/ADMIN
- Архівування об'єктів (як власник/рієлтор/адмін)
- Email-сповіщення про новий призначений об'єкт / запланований огляд

## 🛡️ ADMIN (усе вище +)
**Користувачі** (`/api/manage-users`)
- Список усіх користувачів
- Надати роль рієлтора (`set-realtor/{id}`)
- Забрати роль рієлтора

**Об'єкти**
- Адмін-перегляд усіх об'єктів (`/realty-objects/admin`) з фільтром за регіоном/операцією + пагінація
- Активація / архівування / відновлення будь-якого об'єкта
